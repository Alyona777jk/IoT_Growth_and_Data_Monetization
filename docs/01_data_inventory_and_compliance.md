# 1.1 Data Inventory та Classification

## 1. Реєстр даних IoT-платформи

### A. Personally Identifiable Information (PII)
- **Дані:** Облікові записи операторів/інженерів (email, ПІБ, роль, журнал дій у системі), IP-адреси, геолокація підприємства.
- **Privacy Implications:** Високий ризик при витоку. Потребує суворого розмежування доступу (RBAC).
- **Compliance Requirements:** Обов'язкова згода (Opt-in), шифрування (AES-256), право на видалення (GDPR Art. 17 / CCPA).

### B. Device Telemetry Data
- **Дані:** Показники вібрації, температури, тиску, обертів/хв (RPM), струму, акустичних шумів з сенсорів обладнання.
- **Цінність:** Висока оперативна цінність для запобігання аваріям.
- **Compliance:** Низький ризик PII, але є комерційною таємницею підприємства (Industrial Data Protection).

### C. Anonymized Aggregated Data
- **Дані:** Середній напрацювання на відмову (MTBF) за типами верстатів, середні показники зносу підшипників у галузі.
- **Монетизаційний потенціал:** Дуже високий (продаж бенчмарків та аналітики виробникам обладнання / OEM).
- **Compliance:** Видалення всіх ідентифікаторів заводу/обладнання (k-anonymity, differential privacy).

### D. Derived Insights (AI/ML Outputs)
- **Дані:** Прогнозований залишковий ресурс (RUL), предиктивні рекомендації з ТО, математичні моделі деградації вузлів.
- **Цінність:** Максимальна додана вартість.

## Privacy Compliance Checklist (GDPR / CCPA)

- [x] Data Minimization (збір лише необхідної телеметрії)
- [x] Pseudonymization & Anonymization Pipeline перед відправкою у глобальну аналітику
- [x] Explicit Consent (згода на агрегацію даних для покращення AI-моделей)
- [x] Secure Data Retention Policy (збереження гарячих даних — 90 днів, агрегованих — 5 років)
- [x] Clear Opt-Out Mechanism для передачі даних третім сторонам
